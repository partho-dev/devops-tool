# Refer : https://learn.microsoft.com/en-us/azure/devops/pipelines/agents/docker?view=azure-devops


- Create secrets
```
kubectl create secret generic azdevops \
  --from-literal=AZP_URL=https://dev.azure.com/yourOrg \
  --from-literal=AZP_TOKEN=YourPAT \
  --from-literal=AZP_POOL=NameOfYourPool
```


- Push the docker image created on Docker agent to Azure ACR
    - `docker push "<acr-server>/azp-agent:<tag>"`

- Create the deployment menifest
- Create the deployment: kubectl apply -f ReplicationController.yml
